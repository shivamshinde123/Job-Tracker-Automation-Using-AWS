Your inbox,sorted whileyou sleep.

A fully serverless pipeline that reads every job-application email from Gmail each night, classifies it with Claude on Amazon Bedrock, writes the results to S3, and has your QuickSight dashboard ready by morning.

One run a night. Then back to sleep.

Every piece is a managed service or a function that runs for seconds to a couple of minutes. Nothing idles, so personal-scale use costs well under a few dollars a month.

11:59 pm ET

Wake up

EventBridge Scheduler triggers the Lambda. It reads the last-run timestamp from SSM Parameter Store.

+ seconds

Fetch

Gmail OAuth credentials come from Secrets Manager. Inbox and sent mail since the last run are pulled.

+ a minute

Classify

Each email goes to Claude Haiku 4.5 on Bedrock, which returns strict JSON. Deduped results land in S3 as one file per day.

12:01 am ET

Refresh

The timestamp updates only on success. QuickSight's SPICE dataset refreshes through a manifest file.
